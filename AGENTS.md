# AGENTS.md

Rules for anyone editing this repository: people and AI agents (Claude Code, Codex, Cursor, etc.).
`CLAUDE.md` only imports this file. Keep all rules here.

## Project

Turbo Ability Draft is a Dota 2 custom game: each player builds a hero through an ability draft, under
Turbo rules. Built on the ModDota TypeScript template (TypeScript compiled to Lua for vscripts, and to
JavaScript for Panorama).

- [README.md](README.md): setup, commands, repository layout.
- [docs/DESIGN.md](docs/DESIGN.md): decisions, open questions, unverified assumptions. Read it before
  starting a feature, and update it when a decision changes.
- [docs/research/](docs/research/): dated research snapshots (market data, player feedback, sources).
  Add a new dated file instead of editing old ones, so numbers can be compared over time.

## Hard rules

- **Language**: code, comments, commit messages, PRs, issues and docs are written in English.
- **Original code only.** Other mods (keymil's, Lozrantekh's fork, Legends of Dota, Poelsemix) can be
  studied for ideas. Do not copy their code.
- **Never copy Valve's data into the repo.** Read Dota's data at runtime (`GetUnitKeyValuesByName`,
  `GetAbilityKeyValuesByName`). The only exception is `src/vscripts/config/ability_snapshot.json`
  (ability names, IDs and official draft pools), generated by `npm run abilities:diff -- --update`.
- **Stay faithful to Dota's official Ability Draft** (pool, rules, screens) and extend it. Check
  "Official Ability Draft reference" in `docs/DESIGN.md` before changing draft behavior.
- **One config.** Game rules, the blacklist and the balance overrides go in
  `src/vscripts/config/game_config.json` (typed in `config/types.ts`). Do not hardcode tunable values in
  game logic.
- **License**: the project is proprietary (`LICENSE`, all rights reserved). Third-party code keeps its
  own license: when you add or remove third-party code, update `THIRD_PARTY_NOTICES.md` and `licenses/`.
  Never delete those notices while the code they cover is still in the repo.
- **No monetization** features of any kind.
- **Ask before deciding** anything listed under "Open questions" in `docs/DESIGN.md`, and verify
  anything listed under "Unverified assumptions" before relying on it.
- **Propose a plan before large changes** (new systems, new modes, refactors that touch many files).
- The Mid Only mode is not started. Do not work on it until it is scheduled.

## Commits

Conventional Commits, always:

```
<type>(<optional scope>): <imperative summary, lowercase>

- What changed and why, one bullet per change
- ...

Closes #<issue>
```

- Types: `feat`, `fix`, `perf`, `refactor`, `docs`, `chore`, `test`, `ci`, `build`, `style`.
- Suggested scopes: `draft`, `turbo`, `config`, `ui`, `tooling`, `mid-only`.
- **Never add `Co-Authored-By` trailers, "Generated with ..." lines, or any other AI attribution** to
  commits, PR descriptions or issues. The project's `.claude/settings.json` disables this for Claude
  Code; other tools must be configured the same way.
- Commit only when asked. Never push to `master` without being asked.

## Tracking work

- **GitHub Issues** hold tasks, bugs and playtest feedback. Reference them from commits (`Closes #12`).
- **`docs/DESIGN.md`** holds decisions. When an issue settles a design question, move the decision there.
- **Blacklist and override entries** in the config need a short `reason`, ideally pointing to the issue
  or playtest that motivated them.

## Development notes

- Development happens on Windows with Dota 2 Workshop Tools. Agents cannot run Dota: the maintainer runs
  the game and reports console output. Say clearly what was verified (it compiled) and what was not (it
  works in game).
- `npm run build` must pass with no type errors before committing. CI runs the same build.
- Default test map: `dota_launch_custom_game turbo_ability_draft dota`.
- JSON imports in vscripts: use `import * as x from "./file.json"`. A default import compiles to
  `.default`, which is `nil` in Lua.
- Data sent from vscripts to Panorama changes shape: booleans become `0 | 1`, arrays become objects.
